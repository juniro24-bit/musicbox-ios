# 뮤직박스 iOS (폰 안에서만 도는 앱)

서버 없이 아이폰 안에서 전부 돌아가는 네이티브 음악 앱이에요.

**1단계(지금 버전)에 들어 있는 기능**
- 유튜브 링크를 붙여넣어 음악(m4a)으로 가져오기, 내 오디오 파일 올리기
- 라이브러리(검색, 정렬, 즐겨찾기, 제목·아티스트 수정, 삭제)
- 재생, 백그라운드 재생, 잠금화면 컨트롤, 이전/다음, 셔플, 반복, 재생 속도(음정 유지)
- 파형을 보면서 구간 자르기 (새 곡으로 저장 또는 원본에 덮어쓰기)

재생목록, 페이드, 볼륨, 음정 조절, 커버 바꾸기, 취침 타이머는 이 버전이 빌드와 설치까지 되는 걸 확인한 다음에 붙여요.

Mac이 없어서, **GitHub의 무료 Mac 클라우드가 앱을 빌드**하고 **Windows PC에서 아이폰에 설치**하는 방식이에요.

---

## 전체 흐름

```
이 폴더 → GitHub에 올리기 → (자동) 클라우드 Mac이 빌드 → MusicBox.ipa 다운로드 → Sideloadly로 아이폰에 설치
```

## 1. GitHub에 올리기 (처음 한 번)

1. [github.com](https://github.com) 계정이 없으면 만들어요.
2. 새 저장소(New repository)를 만들어요. 이름은 `musicbox-ios` 같은 아무거나 괜찮아요.
   - **Public(공개)** 을 추천해요. 공개 저장소는 클라우드 Mac을 무료로 쓸 수 있어요. 비공개는 무료 사용량이 훨씬 빨리 줄어요.
3. Windows에 Git이 없으면 PowerShell에서 `winget install Git.Git` 으로 설치하고 터미널을 다시 열어요.
4. 이 폴더(`project.yml`이 있는 곳)에서 터미널을 열고 차례로 실행해요. `내아이디` 부분만 바꾸세요.

```
git init
git add .
git commit -m "첫 버전"
git branch -M main
git remote add origin https://github.com/내아이디/musicbox-ios.git
git push -u origin main
```

## 2. 앱 빌드하기

1. 저장소 페이지 위쪽의 **Actions** 탭을 열어요. (올리면 빌드가 자동으로 시작돼요. 처음에는 "워크플로를 켜겠냐"고 물으면 켜 주세요.)
2. **Build IPA** 가 초록 체크가 될 때까지 기다려요. 보통 5~10분 걸려요.
3. 완료된 실행을 눌러 맨 아래 **Artifacts** 에서 `MusicBox-ipa` 를 내려받고 압축을 풀면 `MusicBox.ipa` 가 나와요.

**빨간 X로 실패했다면**: 같은 화면 Artifacts에 `build-log` 가 생겨요. 그 파일을 저한테 보내 주시면 원인을 찾아서 고칠게요. 한 번에 안 되는 건 정상이에요. 이 코드는 Mac 없이 쓴 거라 컴파일해 본 적이 없어서, 첫 빌드에서 오류가 나올 가능성이 꽤 있어요.

## 3. 아이폰에 설치하기 (Windows)

1. 아이폰 **개발자 모드**를 켜요: 설정 → 개인정보 보호 및 보안 → 개발자 모드 → 켬 → 재부팅.
2. PC에 [Sideloadly](https://sideloadly.io) 를 설치해요. 안내에 따라 Apple 웹사이트에서 받은 **iTunes** 와 **iCloud** 도 필요해요. (Microsoft Store 버전이 아니라 Apple 사이트 버전이에요.)
3. 아이폰을 USB로 연결하고 "이 컴퓨터를 신뢰"를 눌러요.
4. Sideloadly에 `MusicBox.ipa` 를 끌어다 놓고, 본인 Apple ID를 입력한 뒤 **Start** 를 눌러요.
5. 설치가 끝나면 아이폰에서 설정 → 일반 → VPN 및 기기 관리 → 내 Apple ID → **신뢰** 를 눌러요.
6. 홈 화면의 "뮤직박스"를 열어요.

(화면 문구는 Sideloadly 버전마다 조금 달라요. 막히면 어느 단계인지 알려 주세요.)

## 4. 7일마다 다시 설치해야 해요

무료 Apple ID로 설치한 앱은 **7일 뒤에 실행이 안 돼요.** 그때 같은 방법으로 다시 설치하면 돼요.

- **앱을 지우지 말고, 같은 Apple ID로 위에 덮어서 설치하세요.** 그러면 가져온 곡이 그대로 남아요. 앱을 삭제하면 곡도 같이 사라져요.
- 자동으로 갱신해 주는 [AltStore](https://altstore.io) 를 쓰면 같은 Wi-Fi에서 PC가 켜져 있을 때 알아서 갱신해요.
- 곡 파일은 아이폰의 **파일 앱 → 이 iPhone → 뮤직박스** 폴더에 들어 있어서, 백업하기도 쉬워요.

## 5. 유튜브가 안 받아질 때

폰 안에서 유튜브 주소를 찾는 방식(YouTubeKit 라이브러리)은 유튜브가 바뀌면 자주 깨져요. 그럴 땐:

1. GitHub Actions에서 **Run workflow** 로 다시 빌드해요. 빌드할 때마다 라이브러리 최신 버전을 받아 와요.
2. 새 IPA를 3번과 같은 방법으로 덮어서 설치해요.
3. 그래도 안 되면 앱의 오류 문구를 저한테 알려 주세요.

그동안 급하게 듣고 싶은 곡은 앱의 **내 파일에서 올리기** 로 넣을 수 있어요.

## 확인한 것과 못 한 것

- 확인한 것: 모든 Swift 파일의 문법(파서로 검사), 빌드 설정 파일 형식.
- **못 한 것**: 실제 컴파일, 아이폰에서 실행, 실제 유튜브 다운로드. 이 환경에는 Xcode와 아이폰이 없어요.
- 특히 불확실한 곳: 유튜브 추출(`YouTubeResolver.swift`), 받은 m4a 정리(`AudioTools.swift`). 오류가 나면 이 파일들이 먼저 의심돼요.

## 알아 둘 점

- 가져오기는 유튜브 이용약관에 어긋날 수 있어요. 내가 들을 권리가 있는 영상만, 개인 용도로 쓰세요. App Store에는 올릴 수 없어요.
- 유튜브 주소 찾기는 폰 안에서만 해요. 영상 주소를 다른 서버로 보내지 않아요.

## 폴더 구성

```
project.yml                     빌드 설정 (XcodeGen이 Xcode 프로젝트를 만들어요)
.github/workflows/build-ipa.yml 클라우드 Mac 빌드 설정
MusicBox/
  App/                          앱 시작점
  Models/                       곡 정보, 저장 위치
  Services/                     재생, 가져오기, 오디오 처리
  Views/                        화면
  Resources/                    앱 아이콘
```
